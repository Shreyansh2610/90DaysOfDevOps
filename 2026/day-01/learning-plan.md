# 90 Days DevOps Learning Plan

## Current Level
I am a working professional with 2 years of experience as a Laravel Developer. I have experience in web development, Docker basics, Linux server handling, VPS hosting, and deployment troubleshooting. Now I want to transition into DevOps and Cloud Engineering to build scalable infrastructure and improve my career growth.

## My Understanding of DevOps & Cloud
DevOps is the practice of improving collaboration between development and operations using automation, monitoring, CI/CD, containerization, and cloud platforms. Cloud Engineering helps build scalable, reliable, and cost-effective infrastructure using services like AWS, Docker, Kubernetes, and Infrastructure as Code.

## Why I Am Learning DevOps
- To become a complete software engineer with deployment and infrastructure skills
- To increase my career opportunities and salary package
- To confidently manage production-grade applications and cloud infrastructure

## My 90-Day Goals
1. Deploy a production-grade application using Docker and Kubernetes
2. Build CI/CD pipelines using GitHub Actions or Jenkins
3. Learn AWS fundamentals and host scalable applications on the cloud

## Core DevOps Skills I Want to Build
- Linux troubleshooting and server management
- Docker, Kubernetes, and container orchestration
- CI/CD automation and cloud deployment

## Weekly Time Commitment
- Weekdays: 2 to 3 hours daily
- Weekends: 5 to 6 hours daily
- Total: Approximately 20 hours per week

## My Consistency Plan
- Complete daily DevOps tasks without skipping
- Practice hands-on implementation instead of only watching tutorials
- Push code and notes regularly to GitHub
- Share weekly learning updates publicly on LinkedIn
- Revise previous topics every Sunday

## Where I Want to Reach
By the end of these 90 days, I want to confidently work with Linux, Docker, Kubernetes, CI/CD pipelines, and cloud deployment so I can apply for DevOps Engineer roles and manage real-world infrastructure projects.
